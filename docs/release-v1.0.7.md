# RinkoCamera 1.0.7

首个以 RinkoCamera 名称公开发布的版本。

- 软件名称、项目、命名空间、程序、桌面快捷方式、安装包统一改为 RinkoCamera。
- 保留 TSUKI 角色主题、应用图标、紫灰与浅蓝配色，以及 `(｡･ω･｡)ﾉ♡`。
- 没有新配置时可读取旧版 LocalRecorder 设置；新增两项配置兼容回归测试。
- 公开源码采用 MIT，角色素材使用独立许可；发布包附带第三方许可及 WiX 对应上游源码。
- 提供离线 Setup、MSI、self-contained win-x64 便携版、源码 ZIP 和 SHA-256 校验文件。

## 验证范围

本机 Windows 11 x64，.NET SDK 8.0.426，Windows SDK 10.0.26100.86。
Release 构建通过，0 警告、0 错误；29 项常规测试通过，4 项可选桌面硬件测试跳过。
测试包含状态机、文件保存、配置、倒计时、真实 H.264 编码方向、音频 PCM 转换、
WPF 关闭协调器、下拉框标签，以及本次新增的改名后配置兼容。

本版本未重做长时间录制、60 FPS 性能认证、设备拔插和干净系统安装/升级测试。
之前版本的实际录制记录在 docs/regression-1.0.2.md 与 regression-1.0.4.md。
当前已知限制与运行要求见仓库 README；安装文件目前没有代码签名。

旧的 docs/regression-1.0.x.md 保留历史产品名和旧文件路径，不代表当前下载名称。
